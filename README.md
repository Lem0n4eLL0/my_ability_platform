# GigAnt 🐜

Платформа верификации навыков IT-специалистов. Позволяет подтверждать технические навыки через стандартизированную систему тестирования, а работодателям — быстро оценивать реальный уровень кандидатов.

## Описание

GigAnt решает проблему недостоверных резюме в IT-рекрутинге. Платформа сочетает верификацию личности с практической проверкой навыков, предоставляя работодателям гарантированно достоверные данные о кандидатах.

## Стек технологий

### Frontend

- **React 18** — UI-библиотека
- **TypeScript** — типизированный JavaScript
- **React Router** — маршрутизация
- **Redux Toolkit / Zustand** — управление состоянием
- **Axios** — HTTP-клиент
- **Sass / Tailwind CSS** — стилизация
- **Storybook** — документация компонентов
- **ESLint + Prettier** — код-стайл и линтинг

### Backend

- **Spring Boot 3.x** — основной фреймворк
- **Spring Security** — аутентификация и авторизация
- **Spring Data JPA** — работа с БД
- **PostgreSQL** — основная база данных
- **Spring Validation** — валидация данных
- **JWT** — токены для авторизации

### Инфраструктура

- **Docker** — контейнеризация
- **Docker Compose** — оркестрация сервисов
- **Nginx** — reverse proxy
